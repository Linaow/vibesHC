# 🍎 Newtonian Universe: Principia Interactive

An interactive, high-fidelity web experience exploring the foundations of classical mechanics. This project blends scientific precision with playful web design to visualize the "source code" of our physical reality.

---


## 🚀 Overview

**Newtonian Universe** is a single-page educational platform built with vanilla web technologies. It guides users through the Three Laws of Motion, explores derived scientific principles (like Centripetal Force and Momentum), and concludes with a real-time gravity simulator.


## 🛠 Features

- **The Three Laws:** Interactive breakdown of Inertia, Acceleration, and Reaction.
- **Physics Engine Game:** A "Gravity Bench Press" mini-game where users must overcome a constant acceleration vector to reach escape velocity.
- **Derived Logic:** Cards explaining the mathematical rules behind Impulse, Kinetic Energy, and Gravitation.
- **Modern UI/UX:**
    - **Progress Tracking:** A real-time scroll-depth indicator at the top of the viewport.
    - **Scroll Reveal:** Smooth entrance animations for scientific concepts.
    - **Interactive "Eureka" Moment:** A clickable falling apple experiment in the hero section.

---

## 🧬 Scientific Accuracy

The site's game logic follows basic Newtonian kinematics:
`Δv = (F_user / m) - g`

Where:
- **Law I (Inertia):** Objects maintain velocity until gravity or user input acts on them.
- **Law II (Acceleration):** Click-based force impulses increase the upward velocity.
- **Gravity:** A constant negative acceleration vector pulling the apple back to the "ground."

---

## 💻 Tech Stack

- **HTML5:** Semantic structure for educational content.
- **CSS3:** Custom "Midnight Science" theme using CSS Variables and Flex/Grid layouts.
- **JavaScript (Vanilla):** Custom physics loop and DOM manipulation (Zero external dependencies).

---

## 🔧 Installation & Usage

1. Clone the repository.
2. Open `index.html` in any modern web browser.
3. Scroll to explore the laws; click the apple in the game section to defy gravity.
